Ứng dụng Web Flask **Phân loại nội dung bài đăng diễn đàn Tiếng Việt** sử dụng kỹ thuật Xử lý Ngôn ngữ Tự nhiên (NLP).

---

## ✨ Tính Năng

- 🔍 **Chuẩn hóa văn bản Tiếng Việt:** Tách từ, loại bỏ stop words, chuyển về dạng chuẩn.
- 📊 **Phân loại bài viết:** Phân tích chủ đề bài đăng tự động.
- 🌐 **Giao diện Web Flask:** Cho phép nhập đoạn văn bản và xem kết quả phân loại ngay lập tức.

```bash
git clone https://github.com/nguyenhuynhdt37/vietnamese-nlp-analysis.git
cd vietnamese-nlp-analysis
pip install -r requirements.txt
python3 app.py
```
